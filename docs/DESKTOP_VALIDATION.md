## 开发与安装态自动化

`tools/verify-desktop.mjs` 驱动真实 Electron 窗口和现有业务页面。开发入口的基础自动化通过；安装态 **28 项检查通过**。最终交付以 `outputs/desktop-preview/verification.json` 中的 `ok`、检查清单与 `installerSha256` 为准，校验值须与同目录安装包一致。

安装验证使用源码目录之外的 `D:\Apps\.rcc-desktop-verification\` 下全新目录；安装路径和数据路径含中文及空格。应用工作目录指向安装目录，运行环境的 PATH 仅保留 Windows 目录，不提供系统 Node；后端与静态页面均从安装包读取，不会向源码的 node_modules 回退。
