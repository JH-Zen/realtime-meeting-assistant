# v0.1.0-preview.1 · Windows 核心预览版

- 下载并运行 `RCC-Core-Setup.exe`，安装后双击 `RCC.bat`，在页面点击「模拟讲解」。
- 核心包自带 Node.js，无需另外安装 Node 或填写 API Key 即可体验模拟流程。
- 包含字幕、增量导图、问答和会话导入/导出；默认不执行真实语音识别或真实模型推理。
- 不含 Python、真实 STT/embedding 权重及 embedding 可选运行时。真实模式须另行配置。
- 安装包未签名；这是工程预览版本，已知问题与能力限制见 README。
- 重装保留用户 `.env`；包含项目、依赖及 Node.js 许可证。
- 发布流程执行类型检查、lint、构建、281 项自动测试和安装态冒烟验证。
- 冒烟验证覆盖安装、重装保配置、页面/API、模拟字幕和会话导出，不替代真人麦克风与真实模型验收。
- `SHA256SUMS.txt` 提供安装包 SHA-256；`release-metadata.json` 记录对应源码与运行时版本。
