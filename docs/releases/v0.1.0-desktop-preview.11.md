# Windows 桌面预览 0.1.0-desktop-preview.11

2026-10-23。按用户明确要求上传当前已验证版本；后续功能另升版本。未完成全部产品验收。

## 本版内容

- Electron独立窗口管理配套Node后端，动态回环端口、单实例、启动失败提示与关闭清理；保留真实React业务页面和旧浏览器开发入口。
- 原生Windows安装向导，安装位置与快捷方式可选，程序和用户配置/SQLite/日志分开，重装保留数据。
- 结束后复习/问答、本机会议列表、刷新和重启恢复；索引与导图有显式限量补建及持久处理账本。
- 新音频链路保存可观测缺口和源时间；第11版增加实时索引/导图任务记录，支持实时/手动/全部筛选并保存来源段关联。
- 当前开发协作按用户指示使用GPT agents。界面原型保留示例标签，未包装为实际业务。

## 安装与校验

下载 `RCC-Desktop-Preview-0.1.0-desktop-preview.11-Setup.exe`，双击安装。默认使用模拟模式；真实STT需要另备Python及模型，核心包不包含模型/embedding运行时、密钥、会议库或录音。预览版未签名。

本地已验证安装包205684736字节，SHA256：

`db09af54311b6972f58c0b4db61a5959641c94897b70ac519db31ea0b11de1c8`

GitHub附件由Windows Actions针对本版源码重新构建，并须通过实际安装回归后发布；构建字节可能与本地产物不同，下载附件以其配套SHA256文件和validation-summary为准，不能把本地SHA当作远程包校验值。配套SHA256文件与脱敏验证摘要随包提供。安装后的用户数据在 `%LOCALAPPDATA%\RCC-Desktop-Preview`；没有旧版数据自动迁移。
