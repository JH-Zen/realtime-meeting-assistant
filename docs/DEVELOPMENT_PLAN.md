## 3. 当前能力边界

- 以单用户、本机、同一时间单场会议为主；已有最小本机列表与恢复，没有搜索、重命名、删除等完整历史管理。
- 麦克风采集不等于系统声音/会议软件声音采集，当前不承诺后两者。
- 无自动说话人分离；新界面的人名与头像只是示例，不能作为已实现功能。
- 当前没有完整的原文纠错、录音保存与回放流程；时间引用只能定位文字，不能承诺播放对应音频。
- 本地 STT/embedding 不代表全流程离线；远程 LLM 会接收选取的上下文与问题。
- 转写、摘要、导图和回答都可能出错；时间标签存在也不代表结论受原文支持。
- 未签名 Windows 预览包；其他系统、更新回滚、完整卸载和生产部署尚未验收。

## 5. 麦克风必须分层验收

| 层级 | 要确认的事 | 当前结论 |
|---|---|---|
| 采集代码自动测试 | 初始化失败会释放资源，停止会关闭模拟音轨与音频上下文 | 本轮覆盖构造上下文失败、worklet/恢复失败、退出及迟到授权取消；使用替身对象，数量见 M1 记录 |
| 本机真实设备 | 权限允许/拒绝、无设备/占用、实际音频帧、暂停/结束释放设备 | 待实测 |
| 桌面虚拟麦克风 | 固定 48 kHz WAV 经 Chromium 原生采集与 AudioWorklet 输出 16 kHz PCM，再经后台上传 | 自动化通过；权限选择由测试驱动，接收端不执行识别 |
| 浏览器到 STT | 16 kHz PCM 经 WS 到 Python worker，输出实际讲话的 partial/final | 固定语音文件经桌面原生采集和真实 CPU 模型通过；实际设备讲话待验收 |
| 完整会议 | 转写入库，导图/摘要/问答可用，结束后刷新与导出完整 | 待真实模型联测 |

首轮用例：

- 正常说话、停顿、数字与专有名词；转写内容必须对应实际讲话，而非模拟讲稿。
- 权限拒绝、无麦克风、设备不可用；提示明确，不留下假录音状态。
- 暂停后不继续采集，继续后正常恢复；结束、关闭页面后设备确实释放。
- 分别中断页面到后端、后端到 STT 的连接，检查缺口、恢复与时间引用。
- 记录设备、Windows/浏览器版本、模型与参数、持续时长、延迟、错误样例及资源释放结果；只保存测试所需资料。
