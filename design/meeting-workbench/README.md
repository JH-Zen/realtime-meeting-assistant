# 会议工作台 · 界面预览 01

参考 Qoder 应用的工作台布局：深灰底色、窄导航栏、会议列表、标签式内容区与可收起的 AI 侧栏。产品名“听见”为临时设计名称。

双击 `index.html` 即可离线查看，无需安装依赖。也可以通过本地静态服务打开。

- 可以切换转写、纪要、导图，点击来源定位转写。
- 可以搜索、切换示例会议，查看新建会议空白状态。
- 可以暂停/继续/结束演示，勾选待办、导出示例 Markdown。
- 可以体验预设问答、明暗主题、侧栏收起与小屏布局。
- 所有内容均为虚构示例；不录音、不连接后端或 AI 服务。
- 保留现有前端、安装目录、桌面快捷方式与 GitHub Release。

这是用于确认视觉与交互方向的独立原型，尚未接入实际会议能力。
